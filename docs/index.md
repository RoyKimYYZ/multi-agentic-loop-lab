## About This Project

This is a learning scaffold for practicing:
- Parallel AI agent development with GitHub Copilot
- Git worktrees for branch isolation
- Vertical slice architecture
- FastAPI + React full-stack development

It is intentionally simple. No database, no auth, no production infrastructure. The goal is clear, teachable code.
